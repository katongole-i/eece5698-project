## Testing
To evalute the correctness and speed of the hardware logic, execute the `./run_compare.sh` script and choose one of the displayed mps files.
- NOTE: The large mps file takes an excessively long amount of time to run. Its output was validated in C simulation but not on hardware.

## Repo Structure
The finalized builds are located in the `/builds` folder. The builds were generated from the `/ftran_u_top` folder. The inputs used for the script come from `/ftran_u_top/inputs`.
